自动布局基础 + 创建按钮

课程：Figma Design for beginners
对应章节：Auto layout fundamentals + Create the button
时长：约 10 分钟
核心目标：用自动布局做出能随文字长度自动伸缩的按钮，并把它变成可复用的主组件。

这一章要解决什么问题

很多新手会用一个矩形当背景、再叠一个文本当标签，然后用 Frame 包起来。看起来能用，但只要标签文字变长或变短，就得手动改尺寸，非常麻烦。

正确的做法是：先写文字，再给文字加上自动布局，让 Frame 自己根据文字内容“拥抱”大小。这样按钮永远刚好包住文字，改标签不用再手调尺寸。

自动布局是什么

自动布局（Auto layout）让一组元素自动排列、自动间距、自动调整大小。你改内容时，布局跟着变，不用反复手动对齐。

  • 方向（Flow）：子元素可以水平排、垂直排，或者自动换行。
  • 内边距（Padding）：父容器和子元素之间的留白。
  • 间距（Gap）：子元素之间的距离。
  • 对齐（Alignment）：子元素在父容器里怎么对齐。
  • 尺寸模式：
    • Hug contents：适应内容（跟着内容变大变小）
    • Fill：填充父容器
    • Fixed：固定尺寸

快捷键：选中图层后按 Shift + A，就会生成一个带自动布局的父 Frame。

实际例子：做通知卡片时，宽度可以固定（Fixed），高度设成 Hug contents。这样消息变长时卡片只往下长，不会左右乱跑。

动手：创建按钮

1. 添加文本图层

  1. 启用文本工具（工具栏的 T，或按键盘 T）。
  2. 在画布上点击，输入 Button。
  3. 字体保持 Inter 或换成你喜欢的。
  4. 在右侧 Typography 区域设置：
    • Font weight：Semi Bold
    • Font size：18
    • Line height：Auto
    • Alignment：Center

2. 添加自动布局

  1. 选中刚才的文本图层。
  2. 按 Shift + A。Figma 会自动生成一个带自动布局的 Frame 包住文字。
  3. 双击 Frame 名称，改成 Button。

3. 给按钮加样式

  1. 选中 Frame 里面的文本图层。
  2. 在 Fill 的颜色框旁边输入 F 然后回车。Figma 会自动补成 #FFFFFF（纯白）。
  3. 再选中外层的 Button Frame。
  4. 在 Fill 区域点加号添加填充。
  5. 在颜色框输入 0 然后回车，会变成 #000000（纯黑）。
  6. 在 Appearance 区域把 Corner radius 改成 8。

4. 调整自动布局属性

选中 Button Frame 后，右侧会显示 Auto layout 和 Resizing 相关选项。

  • 保持宽高都是 Hug contents（适应内容），这样标签一改，按钮就自动跟着变。
  • 把 Horizontal gap 设为 10。
  • 把 Horizontal padding 设为 16，Vertical padding 设为 10。

小提示：第一次加自动布局时，内边距默认是 10，因为 Figma 用的是你的 Big nudge 偏好值。如果之前已经有一个普通 Frame，它会保留原来的间距。

测试一下：把按钮文字改成 “Continue” 或 “Next”，看按钮是不是自动变宽了。

5. 变成主组件

  1. 选中 Button Frame。
  2. 在右侧边栏点击 Create component（或用快捷键 Mac：Option + Command + K，Windows：Ctrl + Alt + K）。

完成后，图层会变成紫色边框，图层面板里的图标也会变成四个菱形。这表示它已经是主组件了。之后可以从左侧 Assets 面板拖出实例来反复使用，改主组件时所有实例都会跟着更新。

要点总结

  • 按钮不要用“矩形 + 文字”硬叠，优先用文本 + 自动布局。
  • Shift + A 是加自动布局最快的方法。
  • 按钮宽高设成 Hug contents，文字一变尺寸就自动变。
  • 内边距（Padding）控制文字和按钮边缘的距离，间距（Gap）控制多个子元素之间的距离。
  • 做成主组件后，可以在整个文件里反复使用，改一处全局生效。
