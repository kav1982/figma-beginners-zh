创建技能列表

课程：Figma Design for beginners
对应章节：Create the skills list
核心目标：把自定义形状和文字组合成可换行的技能列表，并做成组件。

步骤

  1. 加一个文本图层，写 “Skill name”，字体 Inter，字重 Bold/Black，字号 48。
  2. 从 Assets 拖一个之前做的形状实例（比如 Inchworm），和文字垂直居中对齐。
  3. 复制几组，把形状实例通过右侧的 Swap instance 换成其他形状（Diamond 等）。
  4. 选中所有文字和形状，按 Shift + A 做成自动布局，命名为 Content。最大宽度 1000，间距 8，左对齐。因为有多行，会自动变成 Wrap。
  5. 在 Selection colors 里把填充改成黑色。
  6. 再画一个外层 Frame 包住 Content，加自动布局，命名为 Skills list。去掉填充，高度 Hug，水平内边距 24，垂直内边距 80，对齐居中。
  7. 把 Skills list 变成主组件，移到 Components 页面。

要点

  • 技能列表 = 形状实例 + 文字 + 自动布局 Wrap。
  • Swap instance 可以快速换不同形状，不用重新画。
  • 外层再套一层 Frame 控制整体留白，比直接在内容上加边距更灵活。
  • 做成组件后，可以在作品集各页面复用。
