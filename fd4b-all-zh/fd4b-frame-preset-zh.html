用预设创建 Frame

课程：Figma Design for beginners
对应章节：Create a frame using frame presets
核心目标：用官方预设快速创建桌面尺寸的 Frame，作为案例页的基础。

步骤

  1. 启用 Frame 工具（F）。
  2. 右侧边栏会显示各种预设，打开 Desktop 分类，选一个桌面预设。
  3. 画布上会自动出现对应尺寸的 Frame，改名为 Case study exploration。
  4. 如果内容需要更长，可以拖动底部边框把 Frame 拉高。

这个页面后面会包含

  • 带大标题和背景图的 Hero 区域
  • 章节标题
  • 项目描述段落
  • 展示图片
  • 引用块

现在先把结构搭起来，具体尺寸后面再调。

要点

  • 预设比手动画框快，而且尺寸标准，适合做网页或 App 界面。
  • 先用预设建好容器，再往里面填内容，比先画内容再包 Frame 更清晰。
  • 命名要能说明这个 Frame 是干什么的。
