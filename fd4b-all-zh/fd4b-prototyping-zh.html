原型基础

课程：Figma Design for beginners
对应章节：Prototyping fundamentals
核心目标：理解 Flow、Interaction、Connection 三个核心概念，能把静态页面串成可点击的原型。

原型是什么

静态设计只是画面，原型是让画面“动起来”的规则。你可以早期就做原型来验证想法，也可以等设计比较完整后再加交互和动画。

核心概念

Flow（流程）

一个 Flow 描述用户在设计里走的一条路径，比如注册流程、结账流程。每个 Flow 都有一个起点（蓝色预览图标），点它就能预览。

Interaction（交互）

交互由三部分组成：

  • Trigger（触发）：什么时候开始。比如点击、悬停、按键、延迟一段时间。
  • Action（动作）：触发后做什么。最常见的是跳转到另一个画面（Navigate），也可以打开链接、显示覆盖层、滚动到某处、切换组件状态等。
  • Animation（动画）：怎么过渡。比如从右边滑入、淡入淡出、智能动画等。

Connection（连接）

连接就是画布上那些蓝色箭头（有时叫 “noodles”）。它从一个热区（可以点击的地方）指向目标 Frame，把多个画面串起来。

创建第一条连接时，Figma 会自动把起点 Frame 设成这个 Flow 的开始。

实际例子

作品集网站：

  • 点击导航栏的 “Work” → 跳到案例页（Navigate + Instant 或 Smart Animate）
  • 悬停在卡片上 → 卡片轻微放大或变色（Hover + 改 Opacity / Scale）
  • 点击 “Contact” → 打开一个覆盖层表单（Open overlay）

要点

  • 原型 = Flow + Interaction + Connection。
  • 最常用的是：点击某个元素 → 跳转到另一个 Frame。
  • 先把画面做完，再切到 Prototype 标签画连接，效率最高。
  • 预览时用 Present 模式，能直接看到真实交互效果。
