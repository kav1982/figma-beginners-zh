浏览 Figma Design 文件

课程：Figma Design for beginners
对应章节：Navigate Figma Design files
核心目标：认清编辑器的四个主要区域，以及基本移动和缩放操作。

四个主要区域

工具栏（Toolbar）

底部或顶部的工具条。用来移动画布、创建 Frame / 形状 / 文本、发表评论等。

左侧边栏（Navigation panel）

管理图层、页面和组件。有两个标签：

  • File：看当前文件的页面和图层结构
  • Assets：看和使用组件

右侧边栏（Properties panel）

调整选中对象的属性。有两个标签：

  • Design：尺寸、颜色、文字、自动布局等
  • Prototype：设置交互和连接

画布（Canvas）

中间大区域，所有设计都在这里完成。

基本操作

  • 移动画布：按住空格键拖动，或双指在触控板上滑动。也可以按 H 启用手工具。
  • 缩放：触控板双指捏合，或按住 Cmd/Ctrl 滚轮上下滚。
  • 选中对象：直接点击，或在图层面板点名称。

要点

  • 左侧管结构（图层 / 页面 / 组件），右侧管属性（样式 / 交互）。
  • 空格键是最常用的“临时手工具”。
  • File 和 Assets 是左侧两个核心标签，Design 和 Prototype 是右侧两个核心标签。
